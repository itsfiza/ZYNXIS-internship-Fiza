## 📌 Task Overview

The objective of Week 5 was to apply unsupervised learning techniques to discover hidden patterns and groups within a dataset.

For this task, the **Iris dataset** was used to demonstrate clustering techniques.

The following techniques were implemented:

- K-Means Clustering
- DBSCAN Clustering
- Elbow Method
- Principal Component Analysis (PCA)

The resulting clusters were visualized using PCA, and a potential real-world use case for Zynxis was proposed.

---

## 🎯 Objectives

The main objectives of this task were to:

- Understand unsupervised learning
- Apply K-Means clustering
- Apply DBSCAN clustering
- Use the Elbow Method to determine a suitable number of K-Means clusters
- Apply PCA for dimensionality reduction
- Visualize discovered clusters
- Interpret clustering results
- Identify a potential application of clustering for Zynxis

---

## 📊 Dataset

### Iris Dataset

The Iris dataset contains **150 observations** and four numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The original species labels were not used during clustering because this is an **unsupervised learning** task.

The algorithms were allowed to discover groups based only on the feature values.
