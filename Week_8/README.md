## Project Overview

For the final week of my AI/ML internship at Zynxis, I developed an end-to-end AI-powered feedback intelligence system.

The project focuses on analyzing student and intern feedback using Natural Language Processing and Machine Learning.

The system accepts written feedback from a user, processes the text, predicts its sentiment, and presents the result through an interactive Streamlit web application.

---

## Problem Statement

Organizations receive valuable feedback from interns and students, but manually reviewing large amounts of written feedback can be time-consuming.

The objective of this project is to demonstrate how Artificial Intelligence and Natural Language Processing can assist in automatically analyzing feedback and identifying its overall sentiment.

---

## Proposed Solution

The Zynxis AI Feedback Intelligence System provides an automated workflow:

User Feedback  
↓  
Text Preprocessing  
↓  
TF-IDF Vectorization  
↓  
Machine Learning Model  
↓  
Sentiment Prediction  
↓  
Interactive Streamlit Interface

## Machine Learning

The sentiment analysis model was developed during the NLP phase of the internship.

The workflow includes:

1. Preparing feedback data
2. Cleaning and preprocessing text
3. Removing unnecessary text elements
4. Converting text into numerical features using TF-IDF
5. Training a sentiment classification model
6. Evaluating the model
7. Saving the trained model
8. Integrating the model into a Streamlit application

---

## Deployment

The trained model was integrated into a Streamlit web application.

The application was tested locally using:

http://localhost:8501

Users can enter feedback and receive an AI-generated sentiment prediction.
