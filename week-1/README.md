Task:
Perform Exploratory Data Analysis (EDA) on a publicly available housing dataset using Python.
Tools Used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

Generated visualizations for data analysis

Prepared a findings report summarizing key insights
Files Included:
Housing.csv – Dataset
week_01.ipynb – Jupyter Notebook containing the analysis
week 01 Report deliverable.pdf – Summary report of findings
outcome:
Successfully completed exploratory data analysis and gained insights into the housing dataset.
